# Chhath Puja Web Application 🌅

A feature-rich, beautifully designed devotional web application built to celebrate and guide users through the sacred festival of Chhath Puja. 

## ✨ Features

* **Countdown Timer:** Live countdown tracking the days, hours, minutes, and seconds leading up to Chhath Puja.
* **Festival Rituals & Guide:** Detailed cards explaining key festival days and rituals (*Nahay-Khay*, *Kharna/Lohanda*, *Sandhya Arghya*, and *Usha Arghya*).
* **Devotional Audio Player:** Built-in floating music player featuring traditional songs (e.g., Sharda Sinha's *Ho Deenanath*).
* **Wishes & Greetings:** Curated collection of festive blessing cards with direct one-click WhatsApp sharing.
* **Multilingual Support:** Language toggle options for easy accessibility.
* **Atmospheric Design:** Immersive dark mode interface complemented by warm glowing diya animations and clean glassmorphism UI cards.
